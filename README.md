## 自動置換アプリ v1.0.0

Windows 11向けの無料テキスト自動置換アプリです。

### ダウンロード
- **日本語版**：AutoReplaceApp_JA.zip
- **英語版**：AutoReplaceApp_EN.zip
- **日本語版・英語版セット**：AutoReplaceApp_JA_EN.zip

### 特徴
- 文字列の自動置換
- 部分一致・絶対一致に対応
- 置換ルールや設定の保存に対応

### 対応環境
Windows 11

### 料金
無料

### 起動方法
ZIPファイルをダウンロードして展開し、フォルダー内のEXEファイルを起動してください。

初回起動時にWindowsのセキュリティ警告が表示される場合があります。実行する前に、ダウンロード元とファイルを確認してください。

## AutoReplaceApp v1.0.0

A free text auto-replacement app for Windows 11.

### Download
- **Japanese Version**: AutoReplaceApp_JA.zip
- **English Version**: AutoReplaceApp_EN.zip
- **Japanese and English Version Bundle**: AutoReplaceApp_JA_EN.zip

### Features
- Automatic string replacement
- Supports partial and exact matches
- Supports saving replacement rules and settings

### Supported Environment
Windows 11

### Price
Free

### How to Launch
Download and extract the ZIP file, then run the EXE file inside the folder.

A Windows security warning may appear when you launch the app for the first time. Please verify the download source and the file before running it.
